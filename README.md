# Codex Skills

Personal, reusable skills for Codex.

## Skills

- [`hackmd-manage-notes`](skills/hackmd-manage-notes): create and safely update
  HackMD notes in Microsoft Edge while preserving existing content and style.

## Local installation

Keep this repository as the canonical copy and link individual skills into the
Codex skills directory:

```bash
ln -s ~/codex-skills/skills/hackmd-manage-notes \
  ~/.codex/skills/hackmd-manage-notes
```
